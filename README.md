# Telescreen

A Satisfactory mod that adds Small and Large Telescreens: billboard-sized screens that play synced videos, a shared
built-in browser, windows and remote desktops for every player, with 3D audio.

Work in progress. Current state: the screens can be bought in the AWESOME Shop (Telescreen Set, 25 coupons), built
like billboards, and show a test pattern.

Docs: `Docs/Architecture.md`, `Docs/Debugging.md`, `Docs/ReverseEngineering.md`.
